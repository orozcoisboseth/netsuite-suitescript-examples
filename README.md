# SuiteScript 2.x Examples (NetSuite)

This repository contains small, SuiteScript 2.x examples created for
demonstration purposes.

The goal is to showcase common NetSuite scripting patterns such as:
- Record validation
- Client-side form logic
- Custom UI with Suitelets
- REST-based integrations
- Batch processing using Map/Reduce

These examples are simplified and do not represent production code.
They contain no real business logic, IDs, or credentials.
