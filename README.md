# SuiteScript 2.x Examples (NetSuite)

This repository contains small, SuiteScript 2.x examples created for
demonstration purposes.

The repository includes small examples such as:
- User Event and Client Scripts for UI customization
- Suitelets for custom forms and request handling
- Suitelets used to generate PDFs 
- RESTlets for basic integrations
- Map/Reduce scripts for batch processing


These examples are simplified and do not represent production code.
They contain no real business logic, IDs, or credentials.
